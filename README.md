# Engenharia de IA para DevOps e Fullstack

## Visão do Curso

Sou alguém em transição de trabalho com conhecimento em fullstack de um modo geral e abstrato, sem aprofundamento em nada específico ainda.

Meu objetivo com este curso é, através do conhecimento adquirido aqui somado ao que já domino hoje, estar apto a aplicar para vagas melhores de júnior, com mais segurança técnica e projetos para mostrar.

Minhas prioridades, nesta ordem, são:

1. Sair da fase de transição e me posicionar melhor no mercado.
2. Estar apto a disputar vagas júnior melhores, com argumentos técnicos e portfólio.
3. Construir uma base sólida em IA/ML sem ficar travado em teoria desnecessária.

## Estrutura Geral do Curso

O curso está organizado em duas grandes trilhas:

- **Trilha Núcleo**  
  Foco em fundamentos de Machine Learning para quem já programa, com projetos práticos para entender bem:

  - Problemas de ML clássicos
  - Tratamento de dados
  - Métricas
  - Ciclo básico modelo → avaliação → melhoria

- **Trilha de Aprofundamento**  
  Foco em engenharia de IA “de verdade”, conectando ML com o que já conheço de desenvolvimento e DevOps:
  - Engenharia de dados / pipelines
  - MLOps e operação de modelos em produção
  - Fullstack com IA (serviços, APIs, integrações)
  - Projeto integrador com cara de produto
