# Aula 1 – Primeiro modelo de ML

## Problema

Usar o dataset Iris para treinar um modelo que, a partir das medidas das flores, consiga prever a espécie (3 classes).

## Pipeline

1. Carreguei o dataset `load_iris` do scikit-learn.
2. Separei os dados em treino e teste (80% / 20%).
3. Treinei um `RandomForestClassifier`.
4. Avaliei o modelo com acurácia e relatório de classificação.
